# Data-Analytics-Internship-Task2
# Sales Data Analysis and Business Intelligence Dashboard

## Project Overview

This project was completed as part of the ApexPlanet Internship Task 2.

The objective of the project is to perform Exploratory Data Analysis (EDA), answer business questions using SQL, and create a dashboard to visualize key business insights.

## Tools Used

* Python
* Pandas
* Matplotlib
* Seaborn
* SQL (SQLite)
* Google Colab
* Excel / Power BI

## Project Files

### EDA_Notebook.ipynb

Contains:

* Data loading
* Data cleaning
* Descriptive statistics
* Histogram
* Scatter plot
* Correlation heatmap
* Business insights

### EDA_Report.pdf

Detailed report containing:

* Dataset overview
* Statistical analysis
* Visualizations
* SQL findings
* Business conclusions

### SQL_Queries.md

Contains SQL business questions and their results.

### Dashboard.png

Static dashboard displaying:

Total Orders
Total Sales
Average Sales
Total Quantity Sold
Highest Revenue Product


## Key Findings

Identified the highest revenue-generating products.
- Compared sales across different categories.
- Analyzed customer purchasing behavior.
- Examined city-wise sales performance.
- Observed monthly sales trends.
- Explored the relationship between Quantity and Total Sales using correlation analysis.


## Conclusion

The project successfully identified top-performing products, valuable customers, and profitability trends through data analysis and visualization techniques.
